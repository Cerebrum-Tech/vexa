# Asistan tanımları

Bu klasör, çalışma alanınızdaki asistan rollerini tanımlar. `meeting.md` canlı toplantı asistanını
yönlendirir (neyi izleyeceği, transkripti nasıl temizleyeceği, neyi etiketleyeceği ve toplantı
raporunun dili); `meeting-ui.md` ise Toplantı Tuvali görünümünü yazan asistanın arayüz sözleşmesidir.
Her iki dosya da sizindir — davranışı değiştirmek için asistanınızdan bunları düzenlemesini
isteyebilirsiniz.

`meeting.schema.json` toplantı asistanının çıktı biçimidir; makine tarafından okunur, elle düzenlemeyin.
